Routing rules

Hard requirements are filtered first, using what the probes observed rather than what the config claims — a task needing vision only ever sees models that read an image here. What is left is scored on tier, the agent's preferred strengths, measured speed and cost. A pin beats the router; an explicit model in agents.yaml beats auto; and a pin missing a required capability is overridden rather than allowed to fail silently.
